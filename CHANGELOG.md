# astryx-theme-windows98

## 0.1.0

First release as a standalone package, built against Astryx 0.7.13.

- Light mode is the Windows 98 "Windows Standard" appearance; dark mode is the Windows 98 "Rainy Day" scheme.
- Win32 edges: raised window chrome, raised push buttons, sunken fields, and etched nested panels.
- Embossed disabled text, GrayText placeholders, and a period icon registry.
